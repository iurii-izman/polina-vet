# M12 local SEO strategy

Use truthful local signals already present in the profile, Contact, About, metadata, and map link. Do not create near-identical locality pages or imply a private clinic, opening hours, 24/7 availability, or cross-border service. A locality page is justified only when it solves a distinct user problem, remains useful without the keyword, contains genuinely local guidance, and has a truthful service claim.

This follows current Google Search guidance against doorway abuse: [Google doorway abuse policy](https://developers.google.com/search/docs/essentials/spam-policies#doorways). No location landing pages are created in M12. `WebSite`/`WebPage`, Person, Article, and relevant Breadcrumb data remain; VeterinaryCare/LocalBusiness is not added because private commercial operation and ownership are not verified.
