# M12 growth dashboard

Minimum views: traffic trend; source/medium/campaign; top useful pages; Pets/Farm interest; language; contact clicks by channel; urgent entries; map opens; Useful Next Step Rate; and campaign performance.

These are dashboard views over Plausible pageviews and the M12 events, not a warehouse. Configure goals for `useful_next_step`, `contact_click`, `map_open`, and `urgent_open`; segment by the allowlisted properties. Until a provider domain is configured, the dashboard is a ready specification rather than an active report.
