# ADR-001 — Astro + Sanity

Status: Accepted

Decision:
Use Astro for the public frontend and Sanity Studio/Content Lake for structured editorial content.

Reasons:
- static-first public product;
- strong low-JS/performance fit;
- structured multilingual medical content;
- independent editorial workflow;
- future visual preview/editing support.

Do not replace this stack during implementation without explicit product-level approval.
